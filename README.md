## 三分化结构

| 训练日 | 目标肌群 | 动作组数与次数 |
|---|---|---|
| A：推 | 胸、三角肌中束、肱三头肌 | 卧推4组按周递进；上斜卧推4×12；臂屈伸4×12或力竭；仰卧臂屈伸4×5；Y字侧平举3×10或力竭 |
| B：拉 | 背、三角肌后束、肱二头肌 | 单侧钢线下拉4组按周递进；对握下拉4×12；单手器械划船4×12；坐姿划船4×12；钢线弯举3×10 |
| C：腿 | 股四头肌、腘绳肌、臀部 | 单腿硬拉4×12；保加利亚深蹲4×12；颈前深蹲3×15；罗马尼亚硬拉4×12；山羊挺身3×8 |

详细阶段、次数、休息时间和备注均已写入完整知识库。README 和知识库都是普通 Markdown，可直接在 VS Code 中修改。
